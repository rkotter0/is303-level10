A Python program that lets the user explore college football results from `cfb.csv`.

The user enters a season, and the program sorts every team from that season into four categories:

- 10 or more wins
- 8-9 wins
- 6-7 wins
- Fewer than 6 wins

If the season is not in the file, the program says so and lists the seasons that are available.

## How to run

Keep `cfb.csv` in the same folder as `level10.py`, then run:

```
pip install pandas
python level10.py
```

## Sample session

```
Enter a season to analyze: 2020

College Football Results for 2020

10 or more wins:
  Alabama
  BYU
  Coastal Carolina
  ...
```
